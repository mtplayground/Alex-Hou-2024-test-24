# Movable Pulley

<LessonSection id="moving-with-load" title="Moving With the Load">
  <p>
    In a movable pulley, the pulley wheel travels with the load instead of
    staying mounted at the top. That changes how the rope supports the weight.
  </p>
  <p>
    Because the load can be shared by two supporting rope segments, the input
    force can be smaller than the full weight of the bucket. The tradeoff is
    that you have to pull more rope.
  </p>
</LessonSection>
